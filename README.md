# LongDL

Public **privacy policy** page for the **LongDL** Chrome extension — *"DeepL Pro Unlimited – Longer Translations"*.

## About the extension

LongDL splits long text submitted to [deepl.com](https://www.deepl.com) into smaller chunks and submits them sequentially through the DeepL web interface, so you can translate texts that exceed DeepL's free-tier character limit. All translation happens on deepl.com itself — the extension just automates the interactions.

LongDL is not affiliated with, endorsed by, or sponsored by DeepL SE.

## About this repository

This repo hosts the extension's privacy policy as a single static HTML page (`privacy-policy`), suitable for linking from the Chrome Web Store listing and for hosting via GitHub Pages.

Key points from the policy:

- No translated text, names, emails, IP addresses or browsing history are collected or transmitted.
- Translation history, uploaded documents and settings are stored **only on your device** (Chrome local storage).
- Optional, off-by-default anonymous usage analytics via PostHog (EU servers), with explicit opt-in.
